# AI 定时执行

## 首次注册

1. 发现宿主的自动化或定时工具，读取完整 schema。优先使用可长期保存的每日任务；按用户时区和指定时间注册，默认本机时间 09:03。
2. 完成本人登录、页面绑定和首次真实结果验证。执行 `python3 scripts/refresh.py prepare`，取得已复制到私有目录的运行脚本绝对路径。
3. 用下面的提示词创建每日 AI 任务，把运行脚本与数据目录替换为当前电脑实际路径。使用工具要求的调度字段，不手写未核实的工具调用。
4. 通过宿主工具回读实际任务，确认启用状态、时间、时区、提示词和任务 ID。确认长期有效；若工具有 7 天等有效期限制，说明期限并改用本机持久调度，不能声称已长期启用。
5. 执行 `python3 scripts/refresh.py agent-schedule record --job-id <工具返回的真实ID> --time 09:03`。脚本只保存本机关联并启用执行器，不能替代宿主工具的注册与回读。如果保存失败，用宿主工具撤销刚创建的任务。

## 每日提示词

```text
使用 $liepin-resume-refresh，为本人已绑定的猎聘简历执行今天的刷新任务。
读取安装的 SKILL.md，以及本机私有配置和状态。运行 <运行脚本绝对路径> --data-dir <私有数据目录绝对路径> run --scheduled，使用可用的 Python 解释器。
遵守 enabled 暂停标记。每个本地自然日最多一次刷新点击；已经刷新或暂停时跳过。
核对本人账号和简历 ID。保留浏览器自己的登录态、认证和请求封装。成功需有明确结果证据。
遇到登录失效、账号变化、验证码、付费要求或页面改版时停止；点击结果不明确时保留当天记录，不再次点击，不清除 click.json。
不修改简历内容、求职状态、隐私设置，不投递、不发消息。密码、扫码和验证码由本人在网页处理。
成功、暂停和当天已完成时保持安静。只有出现新的需要本人处理的异常，或异常恢复时通知本人；同一异常不要每天重复提醒。
```

## 更新、暂停和删除

修改时间：先通过宿主工具更新并回读任务，再用 `agent-schedule record` 保存实际任务 ID 和新时间。切换浏览器或账号后先重新验证。

暂停：执行 `pause`。宿主每日任务必须使用 `run --scheduled`，因此暂停后不会继续点击；也可通过宿主工具禁用任务。

删除：先通过宿主工具删除任务并回读，再执行 `agent-schedule clear` 清除本机关联。`clear` 本身不会删除外部任务。

切换调度方式：先删除原调度，再启用另一种。AI 模式和本机模式均使用同一文件锁和当日记录，不能靠注册两个任务增加刷新次数。

## 可用性

AI 宿主必须能在触发时运行任务，并有权限连接候选人自己的电脑浏览器。纯云端定时任务如果不能连接该电脑，就无法使用其登录态。电脑、浏览器和登录会话仍需可用。

Ego 保留首次登录的专用任务空间；Chrome/Edge 连接本人主动配置的本机 CDP 端口。AI 定时能力取决于宿主，不宣称所有 Agent 都有相同的长期调度功能。
