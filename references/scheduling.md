# 定时执行

## 本机依赖

- Python 3.9 或以上。
- 已安装、可连接的 `ego-browser`，以及本人浏览器中的猎聘登录态。
- macOS 的用户 GUI 会话，或 Windows 的已登录交互式会话。

脚本通过标准库执行调度命令，不存储密码，不导出浏览器 cookies。浏览器本身保留登录态；需要重新登录时由本人在网页完成。

## 安装与时间

用 `schedule install --time HH:MM` 安装。默认每天 09:03，本机时区；这是普通运行时间选择，不代表该时间的曝光效果已被证明。

macOS：创建用户级 LaunchAgent，使用 `StartCalendarInterval`。睡眠时错过的触发通常在唤醒后合并执行；关机期间错过的任务不能保证补跑。脚本不会唤醒电脑。

Windows：创建当前用户的每日交互式计划任务，使用 `/IT`，需要本人登录 Windows。关机或未登录时错过的任务不保证补跑。任务创建和删除命令已用夹具验证，仍须在目标 Windows 电脑现场核验浏览器连接与调度运行。

安装前必须有当前绑定的真实 `success` 或 `already_refreshed` 记录。安装过程复制 skill 到私有运行目录，注册任务后读取调度器状态核验；失败时保持暂停，报告失败。

## 私有数据

macOS/Linux 默认：`~/.local/share/liepin-resume-refresh/`。

Windows 默认：`%LOCALAPPDATA%/liepin-resume-refresh/`。

| 文件 | 用途 |
|---|---|
| `config.json` | 时间、浏览器路径、账号摘要和 UI 绑定 |
| `state.json` | 最近结果、最后确认日期、当前绑定验证记录 |
| `click.json` | 点击前写入的当日记录；异常退出后也能阻止重复点击 |
| `events.jsonl` | 不含简历正文的执行状态日志 |
| `run.lock` | 操作系统文件锁，阻止并发执行 |
| `skill/` | 已安装任务使用的运行文件 |

保留最近 1,000 条执行日志。安装包只含通用文件，私有配置与日志不得打包或上传。

## 故障处理

登录失效：让本人登录后执行 `run --dry-run`；当天尚未点击时可再执行 `run`。

账号变化：重新确认本人账号并生成绑定，不能自动跟随当前登录用户。

网页改版：重新观察按钮与结果，再配置。未核验时不能自动探测后盲点。

点击超时：检查网站是否已经刷新。保留 `click.json`，当天不自动重试。第二天按正常流程检查。

调度不存在：检查本机用户会话后重新执行 `schedule install`。`status` 只显示执行状态；`schedule status` 才读取实际注册情况。

macOS 的系统通知取决于本机通知权限。Windows 结果保存在私有日志和 `status`，本版本不弹系统通知。成功通常保持安静；需要处理的状态改变时才通知。
